# Mine nettsider

Portefølje- og prosjekthub for Leon Aabaks web-applikasjoner, bygget om til en moderne React- og TypeScript-applikasjon med Vite.

## Funksjoner

- **Prosjektoversikt**: Rask tilgang til prosjekter inkludert NfcReview, SmakSync, Reiseregning, Skolekalkulator, Koble og Oppskriftslista.
- **Støtt prosjekter (Vipps)**: Integrert Vipps-støtte med QR-kode, klikk-for-å-kopiere Vipps-nummer (`9834BU`), og direkte betalingslenke.
- **Responsivt & Mørk Modus**: Full støtte for både lys og mørk modus tilpasset brukerens enhetsinnstillinger.

## Utvikling

```bash
# Installer avhengigheter
npm install

# Start utviklerserver
npm run dev

# Bygg for produksjon
npm run build
```
